# دمج Modern Web Guidance مع UI/UX Pro Max

المراجعة r1 · وافق المستخدم على التنفيذ ورفع التعديلات إلى `origin/main` بعد التحقق. النطاق هو مستودع GIS Development Skills واختبار جلسة Codex جديدة ضمن المشروع.

وافق المستخدم لاحقًا على الرفع مع تسجيل تعذّر تشغيل الأدوات داخل جلسة Codex الجديدة. تمت أيضًا مراجعة تطوير الصفحة الرئيسية والـREADME ضمن التحديث المكمّل المثبت في `FOLLOWUP.json`.

## النتيجة المطلوبة

كل طلب إنشاء أو تطوير ملف HTML أو صفحة أو واجهة تطبيق ويب يختار المهارتين تلقائيًا من سياق الطلب، بالعربي والإنجليزي ومن غير ما المستخدم يكتب أساميهم. تشغيل المسار مشروط بجاهزية المهارتين، مع نتيجة واضحة لأي شرط ناقص.

تشمل القاعدة لوحة معلومات، مكوّن HTML/CSS/JavaScript، والجزء الأمامي من مهمة full-stack. يظل الـ backend البحت، UI سطح المكتب الأصلي، وتعديلات النصوص وحدها خارج المسار المشترك. واجهة خريطة الويب تضم Geospatial Web Mapping أيضًا عند الحاجة، وتستخدم مشاريع سطح المكتب المسار المشترك في جزء WebView المبني بتقنيات الويب.

## مكان الدمج المقترح

يربط `AGENTS.md` المشترك قاعدة تشغيل قصيرة بدليل واحد تحت `references/` يشرح الجاهزية والترتيب. يطابق راوتر النية سياق الواجهة باللغتين ويعرض المهارتين ضمن الخطة. يتعرّف الأيجنت على النسخ المعتمدة من خلال حزمة التوزيع الحالية ومسار الاكتشاف الفعلي في العميل. UI/UX Pro Max الموجود يُعاد استخدامه بعد التحقق من مصدره ومحتوياته. يُراجع Modern Web Guidance في `New Skill/` ومنها يُعتمد كمكوّن مستقل، مع إبقاء الكتالوج والعدادات والأدلة باللغتين متزامنة عند إدخاله في الحزمة.

## مراحل التنفيذ

1. **مراجعة المصدرين.** نقطة البداية المقترحة Modern Web Guidance v1.0.1 عند `64a6d708f5a43f2cd3fde5d4d7db3905ba1bdf65`. نطابق ملف المهارة وحزمة CLI المُصدرة، ونراجع الترخيص Apache-2.0 وملفات النسب الواجبة، وفهرس الأدلة وملفات التشغيل التابعة والحزم والنشاط الشبكي. نراجع مصدر UI/UX Pro Max ونسخته وترخيصها قبل أي إعادة توزيع. يبدأ التحديث لاحقًا بمراجعة الإصدار والتغييرات وإعادة الاختبارات، مع إمكانية الرجوع للإصدار المعتمد السابق. [الإصدار](https://github.com/GoogleChrome/modern-web-guidance/releases/tag/v1.0.1) · [تعريف الحزمة](https://raw.githubusercontent.com/GoogleChrome/modern-web-guidance/v1.0.1/package.json) · [الترخيص](https://github.com/GoogleChrome/modern-web-guidance/blob/64a6d708f5a43f2cd3fde5d4d7db3905ba1bdf65/LICENSE)
2. **التحقق من متطلبات التشغيل.** Modern Web Guidance يحتاج Node.js 22 أو أحدث، ملف المهارة، وحزمة CLI كاملة ومثبّتة بإصدار وبصمة محددين. تجربة `search` ثم `retrieve` لازم ترجع دليلًا بالفعل باستخدام النسخة المحلية. UI/UX Pro Max يحتاج Python 3 شغّال، و`scripts/search.py` ومساعداته وملفات `data/` و`references/` التي يحتاجها الاستخدام المختار. نحلّ المسارات من مجلد المهارة المكتشف بدل افتراض بيئة Claude، ونختبر بحثًا و`--design-system`. نتحقق من أذونات التشغيل واكتشاف المهارتين في العميل. عند نقص متطلب، يبقى المسار المشترك غير جاهز ويظهر سبب النقص. [طريقة استخدام Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance/blob/v1.0.1/skills/modern-web-guidance/SKILL.md)
3. **ربط التفعيل واستخدام النتائج.** قبل كتابة التنفيذ، يجري الأيجنت بحث Modern Web Guidance عن ميزات الويب المطلوبة ويسترجع الأدلة المطابقة. UI/UX Pro Max يحدد نظام التصميم للصفحات الجديدة، وفي التعديلات يستخدم تصميم المشروع القائم ويبحث في الجزء المتأثر. تجمع الخطة قرار التصميم وطريقة تنفيذه بتقنيات المتصفحات المستهدفة، مع دعم لوحة المفاتيح وقارئات الشاشة وبديل للميزات غير المدعومة. تُبنى الإشارات على نية المستخدم والملفات المتأثرة، وتُسجَّل المهارتان مرة واحدة لكل مهمة واجهة. [سير عمل Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance/blob/v1.0.1/skills/modern-web-guidance/SKILL.md)
4. **قبول مستقل في جلسة جديدة ومتصفح حقيقي.** نبدأ بطلب «اعمل ملف HTML بالعربي فيه زر يفتح نافذة تأكيد»، ثم واجهة ويب أو مهمة full-stack بالإنجليزي. نثبت إن الجلسة استدعت المهارتين وطلّعت نتيجة من كل واحدة وإن القرارات ظاهرة في الناتج. نختبر RTL، العرض الضيق والواسع، فتح النافذة بالكيبورد، Escape ورجوع التركيز. نختبر أيضًا طلب backend بحت، وحالة اختفاء متطلب من كل مهارة. نحافظ على سلوك HTML المحلي أو النشر داخل مسار فرعي لو التسليم يتطلبه، ونسجّل اختبارات المتصفحات المنفذة فعليًا.

## الفحص الأولي

- Node.js v26.7.0 اشتغل في الـ shell الحالي ويحقق الحد المعلن. لم يجد فحص المشروع نسخة Modern Web Guidance محلية قابلة للاكتشاف.
- أمر `python` الافتراضي فشل عبر WindowsApps. Python 3.14.7 اشتغل من مساره الكامل. فحص الجاهزية وجد ملفات UI/UX Pro Max الأساسية، ولا يزال تحقق المصدر وتجربة البحث والتصميم مطلوبين قبل اعتماد الاقتران.
- مراجعة المصادر العامة وتسجيل المرشح رقم 0003 وفحص هذه المسودة ضمن نطاق التخطيط. تنزيل الحزمة أو تشغيلها أو تعديل قاعدة التفعيل يتبع الموافقة على المراجعة r1 وأذونات التنفيذ الفعلية. الإصدار الأول المقترح محلي داخل المشروع. توسيع التوزيع إلى عملاء آخرين يحتاج إثبات الاكتشاف والتشغيل في كل عميل.

## حدود التغيير والرجوع

نحافظ على الشغل الحالي في الفرع، ملفات المستخدم، الكتالوج، واجهة الموقع واللغة والهوية. يُحصر الدمج في التسجيل والتوجيه وفحص الجاهزية والتوثيق والاختبارات اللازمة مع حفظ أي تعديلات قائمة. الرجوع يزيل وصلة التوجيه الجديدة ويعيد تعريف الحزمة إلى آخر إصدار معتمد. موافقة التنفيذ أضافت رفع التعديلات إلى `origin/main` بعد التحقق. تغييرات النظام خارج النطاق.
