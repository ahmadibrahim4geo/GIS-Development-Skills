# Original request

بقولك إيه، عايزيني أشوف الجزئية بتاعت الويب آب أبليكيشن لأن إحنا آسف، اللي هو الأبليكيشن موبايل والويب أبليكيشن والتطبيقات الويب والمواقع اللي هي بتبقى خاصة بنظم المعلومات الجغرافية. عايزين نشوف المهارة أو نجهز خطة عشان المهارة تقدر برضه تتعامل مع الحاجات دي لأن إحنا تجاهلناها قوي. فجهز لي خطة وشوف المهارات. طبعاً استغل بقى المهارة بتاعتنا برضه في الخطة بتاعتنا يعني. عايزين المهارة، نشوف المهارات والمستودعات والمشاريع وكل الحاجات الخاصة بيه. يعني في مصادر، في نماذج، في مهارات خاصة بالأبليكيشن الموبايل. كل الحاجات دي لازم نضيفها معانا، فاهم؟ مصادر ويب، كل حتى الشركات، الحاجات المجانية، المستودعات المجانية والمفتوحة المصدر، حتى المدفوعة بس دي حاجات مجانية نقدر نستغلها. فجهز لي بقى خطة علشان نشوف الأمور دي. لأن إحنا تجاهلناها قوي
