## 2. المبادئ الجوهرية غير القابلة للتفاوض / Core Non-Negotiable Principles

> **المبدأ الجامع:**  
> **Discover Before Building. Reuse Before Reinventing. Free and Open Source First. Verify Before Claiming. Integrate Without Regression.**  
> **اكتشف قبل أن تبني · أعد الاستخدام قبل إعادة الاختراع · الحلول الحرة والمفتوحة أولًا · تحقّق بالأدلة قبل الادعاء · ادمج دون تراجع أو كسر.**

1. **Discover Before Building (الاكتشاف قبل البناء):** فحص المشروع الحالي، ثم [`references/project-catalog.json`](../../../references/project-catalog.json) (193 مشروعًا حاليًا)، ثم أدوات الاكتشاف (`search_catalog.py` / `gis_code_discovery.py` / `discover_engines.py`)، ثم المصادر الرسمية، قبل اقتراح كتابة مكوّن جديد أو إضافة اعتمادية جديدة.
2. **Reuse Before Reinventing (إعادة الاستخدام قبل إعادة الاختراع):** الاستفادة المشروعة من البرامج المفتوحة (تخصيص مضيف، إضافة، اشتقاق `source-fork` مدروس، إعادة استخدام مكونات مرخصة، أو واجهة مستقلة مستوحاة وظيفيًا دون نسخ أصول ملكية)، مع تسجيل سبب هندسي (`ADR`) لأي تطوير أصلي جديد. كما ينطبق المبدأ داخليًا على المستودع: توسيع `build_skill_bundle.py` و`gis_code_discovery.py` و`project-catalog.json` بدل بناء أنظمة مكررة موازية.
3. **Free and Open Source First (الأولوية للمجاني ومفتوح المصدر):** الالتزام الصارم بسياسة [`references/free-first-policy.md`](../../../references/free-first-policy.md) وفصل `free-of-charge` عن `open-source` وعن `free-tier` و`commercial`. عدم فرض خدمات مدفوعة أو مفاتيح API أو اشتراكات سحابية صامتة، مع الإبقاء على دعم المضيف التجاري عند طلبه الصريح مع الإفصاح الكامل والبدائل الحرة المناظرة.
4. **Verify Before Claiming (التحقق بالأدلة قبل الادعاء):** تطبيق [`skills/completion-evidence/SKILL.md`](../../../skills/completion-evidence/SKILL.md) ومستويات الأدلة `T0–T4` بدقة؛ فحص التوافق والملفات في التوثيق (`T0`) أو الاختبار الاصطناعي (`T1`) لا يُثبت التشغيل الأصلي (`T2–T4`). كل منصة أو اختبار غير متاح بيئيًا يُسجّل `NOT RUN` أو `UNSUPPORTED` أو `NEEDS_EVIDENCE` دون تزوير نجاح.
5. **Integrate Without Regression (التكامل دون تراجع):** حماية المهارات القائمة (35 مهارة)، والكتالوجات القائمة، وبنية [`AGENTS.md`](../../../AGENTS.md)، وبوابة [`skills/gis-security-guardian/SKILL.md`](../../../skills/gis-security-guardian/SKILL.md)، وسجل التطوير [`.agent-development-log`](../../../.agent-development-log/STATE.md)، وواجهة الموقع ثنائية اللغة (`index.html`, `explorer.html`, `project-wizard.html`, Brand Kit 3.1)، وجميع اختبارات الوحدة الحالية (`tests/`، 75 ملف اختبار حاليًا).
