A / AGENT WORKFLOW

Use with a coding agentاستخدام المهارات مع Agent

You'll need Node.js, a coding agent supporting Agent Skills, and permission to modify an existing project. Review CLI security prompts before installing.تحتاج Node.js ووكيلًا يدعم Agent Skills وصلاحية تعديل مشروعك. راجع طلبات الصلاحيات قبل استخدام أوامر التثبيت.

1. Install the core GIS router١. ثبّت المهارة الأساسية

npx skills add ahmadibrahim4geo/GIS-Development-Skills --skill gis-development

This uses the third-party Skills CLI. It installs instructions, not GIS software or an AI model. Unmerged PR-only skills are not in public main yet.الأمر يستخدم أداة Skills CLI خارجية. يثبت تعليمات، وليس برنامج GIS أو نموذج AI. المهارات الموجودة فقط في PR غير مدموج لن تكون في main المنشور بعد.

2. Select your project type٢. اختَر نوع مشروعك

For mixed projects, start with the core router.

للمشروعات متعددة المجالات، ابدأ بالمهارة الأساسية.

npx skills add ahmadibrahim4geo/GIS-Development-Skills --skill gis-development

3. Ask the agent (editable example)٣. ابعت الطلب للوكيل

Inspect my GIS project, propose a numbered plan before editing, implement approved changes, run real GIS tests, keep numbered development reports and clearly state anything unverified.
افحص مشروع GIS، اعرض خطة مرقمة للاعتماد قبل التعديل، نفّذ المعتمد، اختبر النواتج الفعلية، ووثّق كل خطوة في سجل تطوير مرقم واذكر ما لم تختبره.

The selected example is guidance, not an executable job. Ask the agent to confirm its host capabilities.المثال تعليمات توجهها للوكيل، وليس أمرًا ينفّذ التطبيق مباشرة. تأكد من أدوات الوكيل وصلاحياته.

C / DEVELOPER WORKFLOW

Working on the repository itself?بتطور المستودع نفسه؟

Clone the source and run the automated quality checks; these commands test the repository, not an installed ArcGIS/QGIS application.استنسخ المستودع وشغّل اختبارات الجودة. الأوامر دي تفحص المستودع، مش تشغيل الأداة داخل ArcGIS أو QGIS.

git clone https://github.com/ahmadibrahim4geo/GIS-Development-Skills.git

Node.js + Skills CLI are optional for manual reading. Native GIS acceptance depends on real host availability.Node.js وأداة التثبيت مش مطلوبين للقراءة اليدوية. اختبار GIS الفعلي يحتاج البرنامج المناسب.

Before you accept a delivery:قبل ما تعتمد نتيجة أي تطوير: Check what the agent actually changed, the exact test outcomes, native-runtime limitations, security implications, and the numbered journal. A passing Python check does not prove the UI or GIS processing worked in the host application.راجع الملفات المعدلة ونتائج الاختبار الحقيقية وما لم يُختبر داخل البرنامج، وتأثيرات الأمان وسجل الخطوات. نجاح Python وحده مش دليل إن واجهة التطبيق أو أدواته اشتغلت.
Does installing a skill install ArcGIS, QGIS or ChatGPT?هل تثبيت المهارة يثبّت ArcGIS أو QGIS أو ChatGPT؟

No. A skill gives instructions to a compatible agent. AI model access, GIS software and licenses are separate.لا. المهارة تعليمات لوكيل متوافق؛ نموذج الذكاء الاصطناعي والبرامج والتراخيص متطلبات منفصلة.

Can the agent remember, revise or undo a previous step?هل يقدر الوكيل يكمل أو يلغي أو يرجع خطوة قديمة؟

Only if the agent maintains the project journal. It adds numbered linked revision/rollback reports. A rollback note itself does not revert source code, which needs separate safe authorized execution.يقدر إذا كان سجل التطوير مفعّلًا في المشروع. التعديل أو الإلغاء يسجّل تقريرًا جديدًا مرتبطًا بالقديم؛ التراجع الحقيقي في الكود يحتاج تنفيذًا وصلاحيات واختبارات.

How can I check that an output actually works?إزاي أتأكد إن الأداة شغالة مش مجرد أكواد؟

Require files, tests, output samples and an acceptance report. Native ArcGIS/QGIS/desktop execution is a separate test from source checks.اطلب الملفات والنواتج وعينات الاختبار وتقرير قبول. اختبار تشغيل برنامج ArcGIS أو QGIS مختلف عن فحص ملفات الكود.

Are the skills free and do they require internet?هل المهارات مجانية أو تحتاج إنترنت؟

The skills are free open documentation. Installation and some APIs use the internet. Many GIS test examples run offline; some vendor runtimes and services have separate terms.الوثائق والمهارات مفتوحة ومجانية، لكن التثبيت وبعض APIs يحتاجان الإنترنت؛ أمثلة كثيرة تعمل محليًا وبعض البرامج والخدمات لها شروط مستقلة.

More optional detail:مزيد من التفاصيل الاختيارية: English guide · الدليل العربي · Licensing termsالتراخيص. Everything needed for a first successful use is explained above on this page.طريقة الاستخدام الأساسية كاملة موجودة هنا في الصفحة نفسها.

GIS specialist, cartographer and geospatial software developer. He created GIS Development Skills to bring practical engineering guidance, code references, geospatial data services and starter templates into one open resource. The project focuses on building reliable, testable tools for ArcGIS, QGIS, desktop GIS and mapping applications, drawing on lessons from projects such as MIRSAD to support developers, researchers and contributors.
