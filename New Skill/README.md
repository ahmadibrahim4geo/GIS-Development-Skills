# External skill quarantine

The project registry stores source references, revisions, licensing evidence,
declared effects, dependencies and review receipts. Entries in candidates are
inert records. Use the project-governance CLI to register a source or inspect
an already supplied local ZIP. The inspection reads the archive without
extracting its members.

The approved directory is reserved for separately authorized candidates. The
promotion directory holds proposals supported by license review and observed
runtime evidence. Review records and a clean heuristic scan do not grant
permission to install, activate, execute or distribute a candidate.
