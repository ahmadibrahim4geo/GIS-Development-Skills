# WEB-06 Security & Privacy Controls

- Sanitize all HTML popup values (`WEB-QA-10`) using `escapeHtml` / `textContent`.
- Never bundle paid API secrets or scrape public `tile.openstreetmap.org` endpoints (`WEB-QA-07`, `WEB-QA-08`).
- Enforce [OWASP Web/Mobile Security Reference](../../../../../references/web-mobile-vendor-license-audit.md) controls.
