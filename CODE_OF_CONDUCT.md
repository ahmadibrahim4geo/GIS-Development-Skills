# Community Code of Conduct

GIS Development Skills welcomes developers, GIS professionals, researchers,
students and documentation contributors from every background and experience
level. Participation in repository issues, pull requests and discussions must
remain respectful, technically constructive and safe.

## Expected behaviour

- Be considerate and focus feedback on the work, evidence and user outcome.
- Welcome questions and explain specialist terminology without belittling people.
- Respect different languages, GIS stacks, operating systems and license choices.
- Protect private data, credentials, exact device locations and unpublished GIS
  datasets. Use synthetic or authorized fixtures in public reports.
- Attribute upstream work and preserve its license and usage conditions.
- Disclose test limitations. Do not present static checks as native ArcGIS, QGIS,
  database, browser, mobile or packaged-application proof.

## Unacceptable behaviour

Harassment, discrimination, threats, personal attacks, doxxing, spam, deliberate
misinformation, license evasion, secret exposure and attempts to pressure a
contributor into unsafe execution are not acceptable.

## Reporting and enforcement

For ordinary technical disagreements, use the relevant issue or pull request and
provide reproducible evidence. For private conduct or security concerns, contact
the maintainer using the address in [SECURITY.md](SECURITY.md). Do not publish
private evidence in a public issue.

The maintainer may edit or remove harmful content, limit participation or close a
thread when needed to protect contributors and users. Decisions should be
proportionate, documented privately where appropriate, and based on behaviour
rather than technical preference or identity.

This policy applies to official repository spaces and to public interactions that
directly represent this project.
