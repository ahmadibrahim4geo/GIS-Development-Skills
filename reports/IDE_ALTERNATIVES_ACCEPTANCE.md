# بدائل أدوات التطوير ومراجعة مدخل المهارة

21 نوفمبر 2026 بتوقيت القاهرة · المراجعة المحلية r7

تبدأ القاعدة من نوع المشروع والقدرة المطلوبة. الفاحص يميّز تحرير الكود،
والبناء، ومعاينة الواجهة، والتصميم المرئي. يتحقق من المسارات المعروفة ومن
SDK وحزمة المراجع الخاصة بالإصدار. للوكيل تفضيل أداة مثبّتة إذا استوفت
الشروط، مع إبقاء مسار مجاني متوافق ضمن الخيارات. [دليل اختيار الأدوات](../references/project-governance-workflow.md#read-only-ide-and-toolchain-reconnaissance)

## النتائج على هذا الجهاز

| المطلوب | النتيجة |
| --- | --- |
| بناء WPF على .NET 10 | رشّح .NET CLI عبر استعلام SDK ورصد حزمة المراجع المطابقة. بُني تطبيق WPF واشتغل. استدعى عميل Windows مستقل زر القراءة وأعاد قراءة 3 خلايا صالحة من شبكة QGIS. |
| مصمّم WPF على .NET 10 | رُصد Visual Studio Community 2022. طلبت الأداة تحقق عبء .NET Desktop وتوافق الإصدار مع المصمّم. التصميم المرئي لهذا الهدف NOT RUN. |
| تصميم Qt Widgets على Qt 6 | رُشح Qt Designer المرفق مع QGIS بناءً على بيانات ملف التنفيذ. تشغيل المصمّم والتفاعل معه NOT RUN. |
| تحرير .NET | رُصد Antigravity وVisual Studio. أظهرت المسارات والأوامر المفحوصة أن Rider وVS Code غير مؤكدين في الجرد. حالة Antigravity تظل مرتبطة بشروط الاستخدام والامتدادات. |

اختبرت عينات محلية التفضيل وتوافق إصدار .NET أقدم، والفرق بين المصمّم
ومعاينة WPF، ورفض اقتراح Qt لمصمّم WPF أو محرر بديل لبناء ArcGIS
Pro SDK. اختبار Rider وQt Creator على واجهتيهما بقي NOT RUN.
تُطبق قواعد الرخصة على الأداة الفعلية. Rider له استخدام غير تجاري مجاني
بشروط JetBrains، ولـC# Dev Kit شروط مستقلة عن محرر VS Code.
[شروط Rider](https://sales.jetbrains.com/hc/en-gb/articles/18950890312210-The-free-non-commercial-licensing-FAQ) · [شروط C# Dev Kit](https://code.visualstudio.com/docs/csharp/cs-dev-kit-faq)

## استعراض ملف المهارة الرئيسي

`SKILL.md` في جذر الحزمة نقطة الدخول. يولّده [سكربت بناء الحزمة](../scripts/build_skill_bundle.py).
يحيل إلى [راوتر GIS](../skills/gis-development/SKILL.md) ثم المتخصص، ويحدد
قواعد مراجعة الطلبات المعقدة والأمان وإثبات التنفيذ. أُضيف رابط اكتشاف
الأدوات والبدائل في مدخل الحزمة. توجد تعليمات استخدام عملية بالعربية
والإنجليزية وتبقى جميع الإحالات نسبية في ZIP.

- **نقاط القوة** · المدخل قصير، ومسؤوليات التخصصات موزعة على مهارات منفصلة.
  أوضح قواعد الصلاحيات والفرق بين اختبار الكود والتشغيل الأصلي.
- **نقاط القصور** · قابلية اتباع التسلسل تعتمد على وكيل الاستضافة. المدخل
  يعتمد على وجود المجلدات المرجعية معه. جدول الراوتر السريع يبرز ArcPy
  تحت ArcGIS Pro بينما يظل مسار C# SDK في أدلة التخصص واكتشاف الكود.
  قدرة فتح IDE أو تشغيل مصمّم داخل جلسة مستخدم تحتاج اختبارًا على حدة.
