# نتائج تعديل ملف الوكيل في r9

[الخطة المعتمدة](../plans/archive/0002_Agent-Hardening/PLAN.json) · [التدقيق قبل التعديل](../plans/archive/0002_Agent-Hardening/AUDIT.ar.md)

| مجال القبول | الدليل المرصود |
| --- | --- |
| مدخل الوكيل | اتفق `AGENTS.md` ومدخل الحزمة على فهم الهدف ثم اختيار التخصص ثم فحص المشروع من جذره. يحيل المدخل إلى قواعد الاستئناف والسجل. نجح فحص ملفات الحزمة وروابط الدخول، وتختلف بصمتا حزمتي r8 وr9 رغم أنهما من أساس Git واحد. |
| توجيه التخصص | وجّه الاختبار بالعربية والإنجليزية إصلاح زر الالتقاط إلى تطوير إضافات QGIS مع تدقيق الأوامر كمساند. وجّه طلب ArcGIS Pro SDK إلى مسار C# Add-in. بقي الجمع بين مخرجين مستقلين بحاجة إلى تقسيم ومراجعة. |
| فحص مشروع قائم | اختبرت الحزمة الموسعة على ويندوز حل `Apps.slnx` وفيه تطبيق WPF ومكتبة .NET. حددت WPF و`.NET CLI`، ونجح الاسترجاع من مصدر محلي فارغ والبناء من SDK 10.0.300 بخروج 0. ظهر `App.dll` وبقيت بصمات ملفات المصدر ثابتة. مع `global.json` تالف انتقل البناء إلى `VERIFY_REQUIRED` وأعاد `dotnet --version` خروج 1. |
| متطلبات الخطوة | تثبت اختبارات الانحدار أن غياب Visual Studio يعلّق خطوة التصميم أو البناء التي اشترطته صراحة، ويبقى التحرير والفحص متاحين. المسار المحلي المقدم من المستخدم يثبت مشاهدة الملف فقط ويظل التوافق بحاجة إلى تحقق. |
| سياق جلسة مستقلة | جلسة Codex مستقلة قرأت مدخل الحزمة المحدد صراحة وتحققت من 435 ملفًا. قسمت الطلب لأن فيه مشروعين. في اختبار WPF تجريبي بـ.NET 10 اختارت `dotnet-cli` للبناء، وأبقت تصميم الواجهة في `VERIFY_REQUIRED` بعد رصد Visual Studio Community 2022 دون مكوّن Managed Desktop المطلوب. اختبار .NET 8 علّق البناء أيضًا لعدم رصد حزمة مراجع WPF 8 في الجرد المحلي. هذه الجلسة قرأت الحزمة الموسعة ولم تثبتها في العميل. |
| الروابط والموارد | نجح فحص روابط المدخل الفعلية، وأظهر اختبار انحدار أن الرابط إلى قسم غير موجود يُرفض. دليل المصادر يحيل إلى كتالوج المستودع، ونجح التحقق من 53 خدمة. |
| اختبارات المستودع | 513 حالة في المجموعة الكاملة، منها 512 ناجحة وحالة روابط رمزية متخطاة على ويندوز. نجحت فحوص الكتالوجين، الحزمة، البيان، رسم إحالات المهارات وSecurity Guardian المحلي. فحص الصلاحيات المحلي أثبت أن إعلان الموافقة داخل JSON لا يمنح قدرات التنفيذ. |

حزمة التجربة المحلية `dist/user-testing/r9/gis-development-suite.zip`.

- بصمة ZIP هي `1de00b974a1fe682cd0939bf1cd7e06642aca44c4753988f520fe6160d8dcdbc`.
- بصمة محتوى الحزمة من البيان هي `294129cb9f74d78d9c0ed11a26d6c758587b4297fa6cdcef8d12dcfb79284e7d`.
- سجلات DoneProof وتحقق WPF في `dist/user-testing/r9`.

ما زالت النسخة المثبّتة في إعدادات Codex تحمل مدخلًا مختلفًا عن الحزمة المحلية. تثبيت الحزمة في Codex وVS Code وAntigravity وتشغيل نافذة WPF وتصحيح زر داخل إضافة QGIS فعلية بقيت `NOT RUN`. إتاحة GitHub خارج نطاق هذه المراجعة المحلية.

في تجربة الجلسة المستقلة ظهر التحرير كعمل مستقل عن المحرر حتى مع طلب فحص `--require edit`. عند اشتراط محرر بعينه تسجل علاقة الاعتماد صراحةً بصيغة `--requires-tool edit=TOOL`.
