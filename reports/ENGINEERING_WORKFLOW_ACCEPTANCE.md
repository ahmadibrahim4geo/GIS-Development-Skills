# قبول منسّق الأدوار المحلي

20 نوفمبر 2026 بتوقيت القاهرة · P04 / S4 · المراجعة r3

رُبطت خطة الاختبار بمترجم intent_router وسجل الأدوار والمهارات القائم.
شغّل المنسّق أداة Horn على نموذج الارتفاع الاصطناعي الموجود في المستودع.
كل انتقال ترك حالة مرقّمة مع المعرّف والأثر. أُعيدت قراءة ملف ASCII Grid
ومقارنته بالمرجع قبل قبول الناتج.

| التشغيل | ما رُصد |
| --- | --- |
| المحاولة الأولى | استُخدمت القدم بدل المتر رأسيًا لاختبار الرفض. نتجت خلية مركزية بزاوية 16.95122141° بدل 45°، فسجّلت QA الاختلاف وأعادت الحالة إلى REWORK. |
| التصحيح والاستئناف | استأنفت عملية Python مستقلة الخطة نفسها بعد تصحيح الوحدة. تطابقت الخلايا الداخلية التسع بزاوية 45°، وحُفظت حافة NoData. وصلت الحالة إلى DONE بعد القراءة المستقلة. |
| التراجع | أُلغي اعتماد الأثر النشط وظلّت المحاولتان وبصماتهما متاحتين. عادت الحالة إلى REWORK. |
| التشغيل بعد التراجع | أنشأ الاستئناف محاولة ثالثة. تطابقت بصمتها تمامًا مع المحاولة الثانية، وقبلتها مقارنة DoneProof وقراءة سجل التجربة. |

حُميت المدخلات المرقّمة ببصمات SHA-256 قبل كل تشغيل وبعده. رفضت اختبارات
الأذونات اعتماد JSON وحده، ورفضت مجموعات الإخراج المتداخلة، وتحققت من
أثر التبعية قبل السماح بتشغيل مهمة تابعة. تغيير المراجعة أثناء الاستئناف
يتطلب تشغيلًا مرتبطًا بالخطة الجديدة.

سجّل الفحص النهائي 482 اختبارًا ناجحًا من 483، مع اختبار روابط رمزية متخطى
على Windows. تعثر اختبار توزيع سابق عند إزالة مجلد مؤقت مقفول أثناء تحقق
متوازٍ. اجتاز التشغيل المتسلسل الاختبار نفسه. اجتازت أيضًا فحوص الفهارس
والـmanifest والموقع والأمان وبناء الحزمة المحلية وإعادة فتح ZIP.

التنفيذ المثبت محلي ومتسلسل على Python 3.14.7 بمراجعة SAME_AGENT_REVIEW.
اختبار تعدد الوكلاء داخل عميل مستقل، والتكامل مع منصات خارجية، وتركيب
الحزمة في بيئة نظيفة بقيت NOT RUN. وثّق الدليل تدفّق المكوّنات بـMermaid.
