## القرار الخاص بالإصدارات

يبدأ اختيار التنفيذ من بيئة المشروع والقدرة اللازمة. توثق إصدارات المصادر
المنشورة حدود أمثلتها. يمكن استخدام مثال من إصدار مختلف للتعلّم، ثم تُطابق
APIs والتبعيات مع الإصدار المتاح قبل أي تكييف للكود أو اعتماد للتشغيل.

ربطت أداة اكتشاف الكود بـJSON الصادر من فاحص البيئة. عند تمرير الجرد الفعلي
قرأت الأداة ArcGIS Pro 3.6.0.59527 وأعادت عيّنات Esri لإصدار 3.6 كمصدر
مطابق وفق الوثائق. بقي مثال الفرع 3.8 في مراجع البحث. ظهرت نفس النتيجة عبر
الأمر داخل ZIP المفكوك في مجلد آخر. اختبار اختيار المرجع نجح. بناء C#
Add-in وتشغيله في ArcGIS Pro بقي NOT RUN. مهارة Esri المستقلة مسجلة في
الحجر بوصفها مرشحًا غير مفعّل.

## البنود المفتوحة

- اختبار وكيل مستقل داخل VS Code أو Antigravity، وتكامل عملاء المهارات
  ومراجعة وكلاء مستقلين، واكتمال خريطة الأدوار والأدوات والمكتبات والأدلة.
- استخدام المصمّم المرئي، وArcGIS Pro SDK Add-ins في المضيف، والقبول
  الرسومي الكامل لـQGIS وWebView2 و3D وKML المرئي.
- مشاهد ATYAF وLandsat الفعلية، ومصادر بيانات كل مشروع، وقياس تكلفة
  توكنات الوكيل، والتثبيت في بيئة نظيفة T4.
- تشغيل الماسحات الخارجية وتدقيق التبعيات لكل مكوّن مُدمج عند اعتماده.
  في فهرس الروابط الحالي بقيت 171 من 193 رخصة مصدر بلا تحقق ملف رخصة.
  تظل نتائج مراجعة حقوق المصادر محددة بالمراجعات المشار إليها.
- تقديم PR وCI ودمج GitHub والتحقق بعد الدمج. هذه العمليات مؤجلة في
  نطاق التنفيذ المحلي.
