# قبول مراجعة المهارات الخارجية داخل العزل

20 نوفمبر 2026 بتوقيت القاهرة · P06 / S6 · المراجعة r4

اختبار WPF في P05 استدعى الزر من داخل التطبيق. راجعت مرشح Microsoft
winapp-ui-automation للسيناريو الذي يحتاج عميل Windows UI Automation
خارجي. سجل المرشح هو 0001 في حجر المشروع، والمراجعة المثبتة هي
`e7e4587ad7a6e51c085ad6360a10ede0cee7ab6e`. فحصت ملف المهارة ورخصة المستودع في المراجعة نفسها.
الرخصة المرصودة MIT للمستودع. تشغيل المرشح يحتاج WinApp CLI وقد يشمل
إدخال سطح المكتب وكتابة لقطات. نسخة CLI المتوافقة وتراخيص مكونات التوزيع
لم تُتحقق في اختبار تشغيل. ظل سجل المرشح مرجعًا غير مفعّل.
[ملف المهارة المثبت](https://github.com/microsoft/winappCli/blob/e7e4587ad7a6e51c085ad6360a10ede0cee7ab6e/plugins/winapp/skills/winapp-ui-automation/SKILL.md) · [الرخصة المثبتة](https://github.com/microsoft/winappCli/blob/e7e4587ad7a6e51c085ad6360a10ede0cee7ab6e/LICENSE)

| اختبار الأداة المحلية | النتيجة المرصودة |
| --- | --- |
| ZIP اصطناعي قرائي بملف مهارة ورخصة | READY_FOR_MANUAL_REVIEW ورمز خروج 0. بقيت المهارة معزولة. |
| ZIP اصطناعي يحاول تجاوز التعليمات ويتضمن ملف hook خامل | REJECTED_ISOLATED ورمز خروج 1. سجّل الماسح نوعي الملاحظة، ولم يُستخرج الملف أو يُشغّل. |
| SHA-256 خاطئ أو اسم مسار يتجاوز الأرشيف | أثبتت اختبارات الوحدة رفض المعاينة للتجزئة الخاطئة ورفض الأرشيف المتجاوز. |
| رخصة غير موثقة أو حقوق واعتماديات تحتاج تحققًا | صنّفتها الأداة REVIEW_REQUIRED. |

النطاق هو فحص ZIP وUTF-8 بقواعد الماسح المحلي stdlib-quarantine 1.0.
تضمّن الدليل SHA-256 للعينة، وحدود عدد الملفات والأحجام، ورمز الحكم
ومواضع الملاحظات. يحتفظ سجل المشروع برابط المصدر وبصمته ضمن بيانات المرشح.
نمط تنفيذ المراجعة SEQUENTIAL_ROLE_SIMULATION والمراجعة SAME_AGENT_REVIEW.

NVIDIA SkillSpector وCisco Skill Scanner واختبار تشغيل المرشح الخارجي
بقيت NOT RUN في هذه المراجعة. مجلدات approved وpromotion مهيأة للسجلات
التي تستوفي قرار الترخيص والأمان والتحقق في نطاق لاحق.
