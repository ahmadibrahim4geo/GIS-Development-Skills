# GIS Development Skills artwork

[Current assets and color guide](brand/README.md) · [Brand gallery](brand/showcase.html)

Brand Kit 3.1 uses a geometric G with four teal squares. Its navy mark is for
light surfaces and its white variant is for dark surfaces. The supplied artwork
is used at its intrinsic proportions.

- The homepage, Explorer and documentation use the approved variants in `brand/`.
- The public `logo.svg`, `icon.svg`, `gis-brand-lockup.svg` and `readme-banner.svg` paths provide compatible entry points to the current identity.
- The full local source kit includes extra export sizes. Production builds use the assets under this directory.
