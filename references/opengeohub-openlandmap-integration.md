# OpenGeoHub / OpenLandMap integration reference

Reviewed: 2026-10-30. **T0 only:** reference and architectural design, not a functioning Z-EARTH feature, verified API, or tested layer.

## When to route
- Research code: [scikit-map](https://github.com/openlandmap/scikit-map), [soildb](https://github.com/openlandmap/soildb), [GEDTM30](https://github.com/openlandmap/GEDTM30), [spatial-prediction-eml](https://github.com/opengeohub/spatial-prediction-eml), [spatial-layers](https://github.com/openlandmap/spatial-layers). Route to gis-code-discovery; inspect actual license, per-file provenance, datasets and dependencies. Never copy repository contents without permission. No root LICENSE found during review for soildb or GEDTM30.
- Discover datasets: [OpenGeoHub](https://opengeohub.org/), [OpenLandMap](https://openlandmap.org/), [documentation](https://docs.openlandmap.org/) and [STAC documentation](https://docs.openlandmap.org/020-stac.html). Route through geospatial-data-catalogs then geospatial-data-discovery.
- Static STAC S3 root as published in docs: https://s3.eu-central-1.wasabisys.com/stac/openlandmap/catalog.json ; test actual response before use. Static STAC catalog **is not** necessarily a STAC API with /search, a tile server, or a streaming service.
- For runtime adapters, route to geospatial-api-integration and remote-sensing-pipelines. For desktop controls route to gis-desktop-application-development, geospatial-web-mapping, gis-ui-ux-design-testing and gis-data-flow-diagnostics.

## Z-EARTH Data Explorer (view only)
1. Add a collapsible **Data Explorer** ribbon tab/panel; do not replace existing ribbon commands or convert current option panels to dropdown-only UI. English default with complete Arabic translation and RTL. Category -> verified provider -> collection -> variable/band -> available date -> Add to Map.
2. Categories: land cover/land use, soil, vegetation, climate, water, elevation and more as publishers actually expose. Keep original sources extensible rather than hardcoding OpenGeoHub.
3. **Discovery adapters** (static STAC, STAC API, OGC WMS/WMTS/OGC API Tiles and verified XYZ) are separate from **render adapters** (categorized raster, continuous raster, vector, 3D terrain). OpenLandMap frequently exposes Cloud Optimized GeoTIFFs (COGs) and STAC metadata; use a proven host raster driver or properly secured compatible tiler (e.g. opt-in self-hosted TiTiler). Never invent tile URLs, assume WMS exists or download entire global rasters for display.
4. **Legend:** official class codes, names, colors and NoData for categorical data; units, extent, min/max and color ramp for continuous variables. Dockable, unobtrusive, auto-sync to source/epoch; cite original product and legend version. Offer visibility, layer ordering and opacity.
5. **Timeline:** read actual per-item datetimes, temporal extents, or documented per-band epochs. Handle missing years and irregular steps, daily/monthly/annual precision, and static products (no slider). Never interpolate categorical labels or fabricate years. Example: documented GLC_FCS30D 30 m land cover product 1985–2022, 5-year steps before 2000 then yearly: https://docs.openlandmap.org/016-project.html . Later epochs only when indexed and readable.
6. **Update discovery:** refresh provider metadata on manual action and bounded cache TTL, optionally use ETag/Last-Modified. Compare indexed item IDs and dates; append genuinely new epochs only after verified retrieval, not based on wall clock. Display publication time separately from scene year, and clearly indicate stale/offline/unavailable services.
7. **Safety and rights:** per-provider credential vault (no shipped keys), rate limits/backoff, safe URL allowlist per configured provider and SSRF prevention for any tiler/proxy, CRS and axis-order handling, raster scale/offset, NoData, region coverage (e.g. deserts), tile caching rights, attribution and licenses. Do not assume view permission grants downloading or redistribution.
8. **Acceptance:** T0 provider and license source; T1 deterministic offline fixtures for multi-provider and missing/new years; T2 live legally accessible tile/COG sample; T3 real Windows WebView2/UIA checks for all commands, legend, timeline, layer removal and failures; T4 packaged desktop smoke test. T0 docs are never T3 production proof.

## ملخص عربي
الواجهة تستعرض نوع البيانات أولًا، ثم المصدر، ثم الطبقة والفترة الزمنية الحقيقية مع دليل خريطة متزامن. يكتشف البرنامج سنوات جديدة من فهرس البيانات بعد التحقق منها، ولا يفترض أن STAC يوفر صورًا جاهزة للعرض أو أن جميع السنوات موجودة. يُستخدم كمرجع للوكلاء ولتصميم التنفيذ، لا كدليل على أن الخدمة تعمل داخل Z-EARTH.
