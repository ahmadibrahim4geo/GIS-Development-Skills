# Cross-Agent Adapters

This directory provides out-of-the-box configurations for popular agentic environments:

| Platform | File | Usage |
| :--- | :--- | :--- |
| **Cursor IDE** | [`cursor.mdc`](cursor.mdc) | Copy to `.cursor/rules/visual-assets.mdc` in your target repository. |
| **Claude (Code/Desktop)** | [`claude.md`](claude.md) | Add to Project Knowledge or instructions in Claude settings. |
| **OpenAI / ChatGPT** | [`openai.yaml`](openai.yaml) | Standard interface declaration for GPT actions and skills. |
| **Antigravity / VS Code** | Inherits from parent `SKILL.md` directly. |
